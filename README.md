# ✨ 賴品岑 (Patty) 生日驚喜 ‧ 專屬互動卡片

專為好友 **賴品岑 (Patty)** 打造的高質感互動式生日電子卡片與刮刮樂系統，由 **Bobo** 準備。針對手機與 **Instagram 內建瀏覽器 (In-App WebView)** 進行極致排版與流暢度優化。

🌐 **線上公開網址 (GitHub Pages)**:
👉 **[https://bonny430.github.io/patty-birthday/](https://bonny430.github.io/patty-birthday/)**

---

## 🌟 核心特色與亮點

1. **⏱️ 即時倒數鎖定與定時開放系統**
   - **定時倒數**：設定指定日期與時間開放，用戶端顯示頂級香檳星塵倒計時（天、時、分、秒跳動），時間一到自動觸發全螢幕煙火彩帶並解鎖！
   - **立即開放**：跳過倒數，即時展示生日卡片全部內容。
   - **強制鎖定**：維持倒數期待感。

2. **📸 雙主角拍立得相框 (Dual Polaroids)**
   - **Photo 1 (`assets/photo1.jpg`)**：賴品岑與好友開心自拍大合照，搭配手寫字祝詞：`✨ 願妳的每一歲都奔走在熱愛裡 ‧ 永遠閃亮的 Patty ✨`。
   - **Photo 2 (`assets/photo2.jpg`)**：全班朋友在 Catherine 英文課上指向白板的經典回憶合照，搭配手寫字祝詞：`💖 在 Catherine 課堂展開第三年友情 ‧ 全世界最棒的 Patty 賴品岑 💖`。
   - 支援滑鼠/觸控 3D 視差傾角微動效與點擊高解析度全螢幕檢視。

3. **🎫 雙重互動刮刮樂抽獎系統（飲料一杯 + 神秘小禮）**
   - **Ticket #01：☕ 今日特調 ‧ 飲料一杯兌換券 (`BDAY-DRINK-2026`)**（好友 Bobo 隨時買單）
   - **Ticket #02：🎁 命中注定 ‧ 神秘小禮一個 (`BDAY-GIFT-999`)**（由 Bobo 親手挑選送出）
   - 擬真香檳金與玫瑰粉金屬塗層，支援手指塗刮與真實白噪音音效。
   - 刮開超過 50% 自動解鎖並噴灑彩花，附贈「一鍵刮開」與「一鍵複製兌換碼」。

4. **💌 復古火漆封蠟手寫信箋（Bobo 給 Patty 的真心話）**
   - 紅色火漆印章「岑」與優雅信箋排版。
   - 國三三年情誼的真摯感謝與溫暖祝福。

5. **🎵 純 Web Audio API 八音盒水晶生日旋律**
   - 無需加載外部音檔，瀏覽器內部即時合成水晶八音盒音樂，在手機和 IG 瀏覽器皆能順暢播放。

6. **🔒 隱蔽式管理員後台 (用戶端完全無後台痕跡)**
   - 一般訪客與 Patty 開啟頁面時，**完全不會看到任何管理員按鈕或齒輪圖示**。
   - **管理員進入方式 (Bobo 專屬)**：
     - **方式一（專屬網址）**：在網址後方加上 `?admin=bobo`（例如：`https://bonny430.github.io/patty-birthday/?admin=bobo`）。
     - **方式二（神秘暗號手勢）**：在網頁信箋的火漆印章「岑」或倒數標題上連續點擊 3 次，跳出密碼提示框，輸入密碼 `bobo` 即可開啟！
   - 後台支援一鍵複製分享給 Patty 的倒數專用連結、強制解鎖連結，以及匯出最新 `config.json` 設定檔。
